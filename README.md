# ステラソラ ダメージ計算ノート（非公式・検証中）

ゲーム「ステラソラ」のダメージを、**実測の数字と照らし合わせながら**組み立てている計算ツールと、その検証ログです。
目的は、ランダムに取得する素質・徽章のうち、どれを取ると強くなるかを、通常攻撃／スキル／必殺技／印ダメージごとに比べることです。

非公式の個人プロジェクトです。ゲームの権利は各権利者に帰属します。

## 使い方

静的ファイルだけで動きます（ビルド不要）。

```
python -m http.server 8765
# → http://localhost:8765/sim.html 計算ページ（巡遊者から3人を選び、徽章・ロスレコ・音符・記録レベルなどを選択式で入力）
# → http://localhost:8765/edit.html 素質の効果の入力ページ
```

PCの横長画面（1920x1080）前提です。スマホ対応は、まだです。以前の検証用ページ（ウィロー側・光チーム）はなくし、計算ページに統一しました（`index.html` は計算ページへ移動するだけ）。

## 現時点で分かっていること（要約）

詳細は [SUMMARY.md](SUMMARY.md)。

- 戦闘中の攻撃力は、画面の外ステータス + ロスレコの基礎攻撃 + **記録レベルの固定加算**で組み立てられ、防衛戦の画面と完全一致します（表は `record_level.js`）。
- 属性ダメージ%は加算で、画面の「光属性ダメージ」と一致します。
- 耐性は、有効耐性 = 耐性 − 貫通、倍率 = 1 − 0.25×(E/250)² で一致しました（[外部の解析](https://gist.github.com/AutumnVN/91afd7a37a9743488419b70f07225950)と同じ形）。
- 防衛戦の雑魚は 耐性250・防御倍率1.00、ボス（指名手配・首領討伐）は 防御倍率0.5、耐性は 弱点の属性250・等倍750・耐性の属性2000（2026-10-28 に実測で確定。「弱点×1.875」は耐性250と750の差のこと）。
- 印ダメージも会心し、会心倍率は「発動させたキャラ」の会心ダメージ（付与役は無関係）。

## 情報を募集しています（未解明の点）

| # | 内容 | 実測 |
|---|---|---|
| 1 | **印ダメージの敵ごとの別枠倍率**。式（最大HP×70%×属性ダメージ×(1+印ダメージ%)×会心×敵補正）に、さらに掛かる倍率 | ストンプクラブ 約1.65〜1.68、深層ノ主 約1.41（徽章の有無に依らず一定） |
| 2 | **セイナ(原点)の最大HP**。式で組み立てた値より、実測が12〜20%高い | 防衛戦のHPバフはウィロー ×1.16、他キャラは少し違う |
| 3 | **ティリアの印増幅**。眩い正義Lv7(+345%)だけなら ×4.45 | 実測 ×6.57。別の被ダメ系が重なる？ |
| 4 | 同じ段の2発目が1発目の ×1.0278 | 原因不明 |
| 5 | 「ダメージ減衰係数」「ブレイク係数」「特定ダメージ係数」の正体と、ゲーム内での確認方法 | 未確認 |

ゲーム内で確認できる**実測の数字**や、ゲーム画面の表示・説明文に基づく情報を、Issue で教えてもらえると助かります。
その際、**どのビルド・どの敵・何発目のヒットか**が分かると、照合しやすいです。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `calc.js` `data.js` `data_sup.js` | 検証済みの式とデータ（ウィロー・ナツカ・エレノア、ロスレコ・音符など）。計算ページが使う |
| `sim.html` `sim_ui.js` `sim_engine.js` `sim_data.js` `sim_pots.js` `sim_lr.js` `sim_share.js` | 計算ページ（画面・計算エンジン・キャラと敵のデータ・光チームの素質の効果表）。以前のウィロー側の検証ページとは、全シナリオで一致を確認済み |
| `index.html` | 計算ページ（sim.html）へ移動するだけ |
| `data/lostrecords_jp.json` `data/lr_auto.js` `tools/import_lr_wiki.py` `tools/build_lr.py` | 日本語Wikiのロスレコ（★5・★4・★3の全部）と、その効果を決まった言い回しで読んだもの。ゲーム内では未確認なので、計算ページでは名前に「*」を付ける。手で入れたロスレコ（`sim_lr.js`）が優先 |
| `tools/build_site.py` | 公開用（sim.stella-tool.com）のファイルを `dist/` にまとめる |
| `sim_share.js` | 共有コード（入力の差分を辞書で番号にして、圧縮・英数字化。初期値と違う所だけを出すので短い） |
| `record_level.js` | 記録レベルボーナス表（Lv1〜40） |
| `data/potential_ja.js` | 素質の日本語名（英語名→日本語名）。プリセット共有サイトの名前データより |
| `data/trekkers.json` `data/trekkers.js` | キャラのスキル倍率・ステータス・素質（下記の出典から自動生成） |
| `tools/` | 上記データを作るスクリプト |
| `edit.html` `edit_ui.js` `data/spec_user.js` `data/spec_draft.js` | 素質の効果の入力ツールと、その内容（確認済み／自動の下書き） |
| `data/shared/potentials.json` `docs/shared-data.md` | プリセット共有サイトと共有する素質のデータ（キーはサイトと同じ trekker_id＋role＋name_en）。作り方は docs/shared-data.md |
| `tools/import_jp_wiki.py` `tools/classify_effects.py` `tools/build_shared.py` | 日本語Wikiの取り込み・効果の下書き・共有データの作成 |
| `data/sim_chars_auto.js` `tools/build_chars.py` | 計算ページで選べる残りの35人（英語Wikiのスキルの説明文から、ヒットを自動で作成。未検証）。手で直すときは `sim_data.js` に書く（そちらが優先） |
| `SUMMARY.md` | 検証のまとめ（分かっていること・仮説） |
