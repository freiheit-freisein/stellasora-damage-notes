# 徽章のスクリーンショット読み取り（テスト中）

計算ページの徽章の画面にある「スクリーンショットから読み込む」の仕組みと、分かっていること・工夫していることのまとめ。コードは `sim_ocr.js`（読み取り）と `sim_ui.js` の `ocrBox` `runOcr` `applyOcr`（画面）。

## 方針

- 文字の読み取りは [Tesseract.js](https://github.com/naptha/tesseract.js) 5.1.1。CDN（jsDelivr）から、読み込むボタンを押したときに初めて読み込む（ページを開いただけでは読み込まない）。
- **画像はブラウザの中だけで読む。** サーバーには送らない。サーバーの費用もかからない。
- 最初の1回だけ、読み取りの部品と日本語・英語の文字データをダウンロードする（2回目からはブラウザに残る）。
- 読み取った結果はすぐ入れず、一覧で見せて「この内容で入れる」を押したときだけ入れる。違う所は、入れたあとに手で直してもらう。

## 入力の方法

- 「クリップボードから読み込む」ボタン（`navigator.clipboard.read`）。初めてはブラウザが許可を聞くことがある。使えないブラウザでは Ctrl+V の案内を出す。
- 「画像ファイルを選ぶ」。
- 徽章の画面を開いているときに Ctrl+V で貼り付け（`paste` イベント）。

## 読み取りの流れ（`S.ocrEmblem`）

1. **白い表の場所を探す**（`findPanel`）。画像を幅240pxに縮め、ほぼ白（RGBの最小が232より大きい）の画素が多い行・列から、表の上下左右を決める。見つからなければ、PC版の画面での位置（横 29〜71%・縦 20〜87%）を使う。
2. **切り出して拡大し、白黒にする**（`prep`）。表の幅が約1800pxになるように拡大し（1〜3倍）、明るさ150を境に白と黒に分ける。
3. **日本語で1回読む**（`jpn`、`preserve_interword_spaces`）。項目名と値の間の空白を残して、行を「名前」と「値」に分けやすくする。
4. **値の列だけを数字で読み直す**（`eng`、使う文字は `0123456789.+%` だけ、`psm 6`）。表の幅の 72〜90% の所を切り出して読む。日本語で読むと値が崩れやすいため。
5. **行と値を高さで組み合わせる**。日本語の各行の中心の高さに一番近い、数字の行を使う（行の高さの0.8倍以内）。
6. **項目名を当てはめる**。`EMBLEM_OPTIONS` の名前（属性つきの項目は「光属性ダメージ」のように6属性分）との編集距離で一番近いものにする。名前の長さで割った距離が0.5より大きい行は、表の行でない（見出し・背景の文字）として捨てる。
7. **値を品質の段階に当てはめる**（`snap`）。
8. **素質のレベル上昇**（「○○レベル +3」の行）は、その巡遊者の素質の一覧から当てはめる（下記）。

## 分かっていること・工夫

### 行の数と位置

- 徽章は1枚につき必ず4行なので、全部で12行。並びは必ず 初級 → 中級 → 上級。上から4行ずつを初級・中級・上級に入れる（見出しの文字は使わない）。
- 一番下が切れている画面は11行になる。そのときは「最後の1行が読めていません」と出し、空いた枠は手で入れてもらう。13行以上なら上から12行だけ使う。
- 素質が見つからなかった行も、**捨てずに場所だけ残す**（`nopot`）。捨てると、その下の行が1つずつずれて、違う徽章に入ってしまうため。画面では取り消し線と「（該当無し）」で出し、その枠は空にする。

### 値の読み間違い

- 「12%」が「129%」のように、うしろに余分な数字が付くことがある。読んだ数字が、その項目の品質の段階の値と完全に同じならその品質、違えば **頭が一致する段階の値**（長いほう優先）に当てはめる。
- スキル・素質のレベル上昇の「+3」は、「+」が「1」に読まれて「13」になることがある。「1」のうしろが1〜3の1文字なら頭の「1」を外す。+1 は金、+2・+3 は虹。

### 素質名（崩れやすい）

- 素質名は、下線つきの色文字なので崩れやすい（例：「閃光の奥義」が「関光の和央閉」になった）。
- 候補を、その巡遊者の主力・支援・汎用の素質だけに絞る（`ocrPots`）。候補が少ないので、崩れていても当てやすい。
- 近さは、編集距離と「同じ文字が同じ順に並んでいる数」（最長共通部分列）の割合を平均したもので測る。崩れた文字が多くても、合っている文字の数で選べる。
- 当てる条件：近さ（0が完全一致）が0.5以下、または0.8以下で、2番目の候補より0.1以上近いとき。それ以外は「該当無し」。
- 近さが0.3より大きいとき・値が読めないときは「要確認」の印を付ける。

### 速さ

- 試作のときは1枚13秒かかったが、今の形で1枚 約2.6〜2.9秒（PC、サンプル4枚）。

## 試したサンプル（PC版の画面）

| サンプル | 読めた行 | 結果 |
|---|---|---|
| ウィロー（一番下までスクロール） | 12行 | 全部正しい |
| ウィロー（一番下が切れている） | 11行 | 全部正しい（最後の1行が切れていると分かる） |
| ナズナ | 12行 | 全部正しい |
| フリージア | 12行 | 全部正しい |
| セイナ(原点) | － | 崩れた素質名（閃光の奥義）を、当てはめを強くしてから当てられた |

素質のレベル上昇（遠ざかる潮騒・流彩の障壁・みんな寝転んで・音ゲーステップ）も正しい名前に当てはめられた。サンプル画像と試作ページは `ocr_try/`（git には入れていない）。

## まだのこと

- スマホ版の画面は試していない（表の位置・文字の大きさが違うはず）。
- 本番で実際の徽章画面を読んだ結果は、まだ集めていない。
- スキルレベル・信頼レベルの画面の読み取りは、まだ作っていない（心相は対象外）。
- 2枚に分けて撮った画面を1つにまとめるのは、まだ作っていない。
